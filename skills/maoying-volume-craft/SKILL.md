# 卷纲与单元结构（maoying-volume-craft）

章节节奏归 maoying-beat-pacing 管，本技能管卷与卷之间、单元与单元之间的骨架。

## 卷四定（规划一卷先锁四样）

- **定主题**：每卷是一部独立小说——为本卷单独设定主角行为的驱动力与本卷小主题，围绕主题设事件；每章至少一个冲突 + 一个悬念。
- **定收获**：锁一卷的「收获」——主角在本卷结束时拿到什么（实力/地位/关系/信息）。
- **定上限**：锁本卷实力/能力上限，防战力膨胀与剧情失控。
- **定刻度**：全书级约每 20 万字完成一个大目标（换地图/大阶段），付费连载每 6-7 万字一个中目标——用「目标完成度」切卷，不纯按字数。只锚定大高潮节点，中间细节允许临场微调；全书大纲不锁死（写完前才写完大纲必偏离，长篇须预留大纲深度）。

## 情节五步循环（单元骨架）

① 主角与反角冲突 → ② 主角略占优或略劣 → ③ 反转优劣势、加剧冲突 → ④ 高潮（须跌宕起伏）→ ⑤ 埋伏笔、进入新情节。「突转」是推向高潮的主要推手。强主线文（升级/悬疑）每卷 = 完整三幕式，卷内每个单元再各套完整三幕式；凡支线必推动主线，否则删。

## 支线红线

- 不带主线伏笔的支线：约 6000 字内收束；
- 携带主线伏笔的支线：最长 3 万字；
- 高潮戏同步埋 2-3 个新坑供后续回收（登记走 foreshadows.yml）。

## 期待线并行

- 全书同时运行 3-5 条期待线（升级/复仇/感情/悬案……），每章至少 1 条在推进；任一条完全静止不得超过 3 章；
- 主线节点用一句章末副线镜头（「与此同时，千里之外……」）低成本维持他线牵引。

## 换地图三纪律

1. **先铺垫预告**：提前点出新舞台并埋伏笔，不许突然换图；
2. **换图后短期给表现**：新地图尽快给主角一次立住新期待的表现；
3. **信息分层放**：新地图设定一层一层放，不一次倒完（口径同 maoying-golden-opening 信息释放纪律）。

## 换图 = 重建关系网 + 旧角保温

- 进新地图等同增加人物：主角脱离旧同伴后要重建敌我关系结构，新关系网落 relations.yml；
- 旧地图要角用「决策后果/消息传入」保温（其前因正卡住当前剧情），不许无声蒸发。

## 群像戏份账

- 给每个要角记「上次登场至今的字数距离 + 故事内时间」（不是章数），防角色蒸发；
- 同一卷高度活跃主线 ≤3-4 条，其余冷却待命；群像戏份严禁压过主角线。

## 自检清单（出卷纲后逐项过）

- [ ] 本卷主题、收获、上限、刻度四样锁了吗？
- [ ] 每个单元走完五步循环了吗？突转在哪？
- [ ] 支线超红线了吗？高潮埋新坑了吗？
- [ ] 期待线几条在跑？静止最久的那条几章了？
- [ ] 换图前铺垫预告了吗？旧角保温了吗？
