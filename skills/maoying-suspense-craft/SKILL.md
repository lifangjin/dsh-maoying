# 悬疑与对比（maoying-suspense-craft）

悬疑管读者的好奇心，对比管读者的情绪强度。本技能管「怎么让读者非往下翻不可」。

## 悬疑的定义：悖论，不是反转

悬疑 = **当前世界观下不可能发生、却发生了的事件**：死者复生、规律失灵、不该知情的人知情——读者既有认知被打破，才会非问「为什么」不可。反转与冲突是剧情事件，悖论才是悬疑；把反转当悬疑写，读者只会「哦」一声，不会追。

## 悬念-行动-线索循环

主线悬念按此循环推进：**悬念 → 行动 → 线索 → 线索解答一部分悬念**。

- 线索只解答一部分：每条线索给增量答案，同时留出更大的问号；一次全解答，循环即断。
- 新悬念两个来源：行动过程中自然长出；线索之间互相冲突生出。凭空抛出、无源无据的新悬念不算。
- 行动段必须带卖点（克服困境/升级/探索皆可）；没有卖点的行动段尽量压缩——悬疑不是灌水许可证。
- 数据落账：线索、悬问、误导进 novel/clue-board.yml（clue/question/red-herring/deduction）；主线级悬念同时在 foreshadows.yml 登记排期，回收口径同 maoying-foreshadow-discipline。

## 信息差四象限

关键桥段动笔前先标注属于哪一象限——不同象限驱动不同情绪，不得混放：

- 读者知、角色不知 → **揪心**（看着角色往坑里走）；
- 角色知、读者不知 → **期待反转**（底牌在谁手里）；
- 双知 → **共情爽**（一起看第三方出丑）；
- 双不知 → **惊吓**。

反转的本质 = 信息差揭底：一个单元只安排一次大转折；可一步爆发，也可「打牌式」分段博弈逐张揭底，直到最后一张牌。

## 双线螺旋蓄期待

中期主线用双线螺旋：危机持续加压在前，主角暗中变强不急于解决——读者知道主角已近无敌而反派不知，期待拉满到爆发点一次性兑付（兑付口径同 maoying-beat-pacing 压抑-释放配比）。

## 堵死猜测

抛出悬念后，把读者的主流猜测逐条堵死：给出排除 A 的证据、排除 B 的证据……读者排除到无路可走，剩下的悖论才最抓人。常见翻车：答案明摆着（凶手就是那个一眼可疑的人），读者提前猜中，之后全部泄气。自查：列出读者当前最可能的 3 种猜测，逐一核对正文是否已给出反证或强化。

## 对比：表现力的杠杆

- **层层对比推情绪**（《修真四万年》列车战）：多数修真者以弱小实力决然迎敌（弱小与坚决对比）；少数怯懦者见状自惭归队（先前懦弱与后来勇敢对比）；众人前赴后继不惧死亡（死亡之残酷与战斗之英勇对比）。三层对比把读者情绪逐步推高。
- **反差消解严肃**：用不严肃的手段做严肃的事（电饭锅炼丹），制造反差与呼吸口，也立角色记忆点。
- **专业衬托高明**：一个角色的专业对另一个角色的更专业，衬托后者；小白配角的不屑与事后「震惊 + 巴结」对比，凸显主角强大。
- 悲/怒/暖同理：情绪强度来自落差，不来自形容词堆叠。
