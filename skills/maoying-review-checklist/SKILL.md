# 审校清单（maoying-review-checklist）

逐章审稿与一致性扫描的执行标准。输出统一按三层严重度：**P0 阻塞**（不改不能定稿：逻辑硬伤、人设崩坏、伏笔矛盾）、**P1 应改**（明显影响体验：节奏塌、钩子弱、语言拖沓）、**P2 可改**（打磨项：用词重复、对话标签单调）。每条问题给出位置（章节+引用原句片段）与改法建议，不直接改稿。

## 六层检查

### 1. 语言层
- 病句、搭配不当、指代不明；
- 同一词汇短距离重复（一段内 2 次以上）；
- 对话标签单调（连排「XX 说」）与对话腔书面化（人物说话不像该人物）；
- 景物/心理描写超过 3 段无剧情推进。

### 2. 节奏层
- 开头 300 字内入戏（无出事则记 P1）；
- 章内至少一次起伏（全章平铺记 P1）；
- 章尾钩子存在且改变下一章前提（无钩子记 P1，钩子空转记 P2）；
- 本章相对前章节奏是否雷同（连续两章同构记 P2）。

### 3. 人设层（对照 characters/ 角色卡）
- 言行符合角色卡的性格与说话方式；偏离必须有剧情内的成因（成长/刺激/伪装），否则记 P0；
- 动机成立：本章角色的关键行动有可信动机；
- 能力边界一致：主角能力/金手指没有无端膨胀（超出已确立的规则记 P0）；
- 配角不工具化：反派行为符合其自身利益逻辑。

### 4. 逻辑层
- 时间线连续：与前章及 timeline.yml 无矛盾（昼夜/季节/时长对得上）；
- 空间移动合理：位置变化有过程或合理解释；
- **信息知情权**：角色只知道他该知道的——不得使用其不在场、无人告知的信息做决策（违者 P0）；
- 因果闭合：本章引入的冲突有来源，本章兑现的铺垫有出处。

### 5. 伏笔层（对照 foreshadows.yml）
- 本章埋设的伏笔是否已登记（未登记记 P1，报给主编转设定管理员）；
- 本章推进/回收的伏笔与台账状态一致；回收是否超出预期但合乎前文；
- 活跃伏笔是否有间隔性提醒（长线伏笔超过 15 章未提及记 P2 提醒）。

### 6. 剧透层
- 本章是否提前泄露后期反转（对照章节大纲与已定稿章节的既有走向）；核心反转的铺垫应可回读成立但当时不点破。

## 输出格式

```
审稿清单：语言✓/节奏✗(P1)/人设✓/逻辑✓/伏笔✗(P1)/剧透✓
P0：（无）
P1-1（节奏）：章中段约 XX 处连续两场谈话无冲突……建议……
P1-2（伏笔）：fs-007 状态台账为 progressing，正文已写回收……建议……
P2：……
```
