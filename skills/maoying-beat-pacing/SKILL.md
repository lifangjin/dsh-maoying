# 爽点节奏（maoying-beat-pacing）

网文读的是节奏反馈。本技能管「什么时候给什么强度的满足」。

## 即时正反馈环（底层结构）

网文的底层反馈结构：**目标 → 行动 → 收获**。收获必须即时、可见、且改变主角处境（拿到东西/实力提升/目标推进），读者每章至少看到环闭合一次；收获同时为下一个目标标价，环环相扣成动机链——收获不给新目标，读者就没了翻页理由。

升级文的展示公式：**困境 → 练功 → 升级 → 碾压**。四拍不必等长：困境要具体（谁/什么卡住主角）；练功可压缩，三五句写清获得了什么；升级要有可感标尺（前后对比）；碾压要兑付此前埋的压抑。不含卖点的日常/感悟章不进此公式，尽量写短。

## 期待感管理

- **双要素判据**：每个拉期待桥段必须同时答得出两问——读者在等什么事件？凭什么信会兑现？「信」的来源：金手指/底牌对读者可见、对角色隐藏；卷内点出「舞台」（大赛/大比/决战），暗示主角终将登台。
- **打破平衡**：场景均势时必须用一个特殊「动作」+信息差打破平衡，读者才会期待「抹平信息差」的过程；获得感必须作用到环境与他人的反应上——收获只有主角自己看着爽 = 毫无爽点。
- 期待线并行与静止超限的处理见 maoying-volume-craft「期待线并行」。

## 爽点类型库

扮猪吃虎（隐藏实力被轻视后展露）、打脸（被挑衅后反击）、升级（实力/地位/财富跃迁）、获得（奇遇/宝物/传承/认可）、复仇（冤屈昭雪）、解谜（悬念揭开）。**同类型爽点连用不超过 3 次**——读者会疲劳，第 4 次必须换类型或升级规模。

## 打脸节拍配比

打脸分两档，别混用同一套刻度：

- **单元小打脸**（对齐中爽点节奏，3-5 章一个）：装逼四拍按 **1:2:1:1 配比**排布——铺垫（心理/感情）、压制（愤怒值）、升级（期待感）、打脸（爽感），比例不变、拍长随周期伸缩（3-5 章周期下拍长半章到 2 章）。打脸四部曲：挑衅 → 隐忍 → 反转 → 余震；余震必写：清点/超额收获、围观震惊、嘲笑者求饶——没人赞叹就不爽；打脸 = 反击 + 获胜 + 获得赞美，缺赞美的打脸只有一半爽。扮猪吃虎三字诀：暗（知情者窃喜）、爽、装（不点破）；知情者分层——高手识货、龙套当炮嘴。
- **大打脸弧**（同一反派对线的恩怨总清算，跨度自查超期即调）：飞卢约 3 章一个完整周期，番茄 5-8 章，七猫 8-12 章，起点 15-20 章（爆发力须更猛）；弧内小爽点照常按三级曲线供给，不因蓄大招而空窗。
- **单元循环判据**：每个事件以主角收获结尾（可吃小亏不吃大亏，所得 > 所失）；法宝等可消耗收益尽快用出，不积压。

## 三级节奏曲线

- **单章小爽点**：每章（2000-4000 字，免费平台收敛 2000 字档，口径同 style.md 平台分档）至少一个小满足——一次机智应对、一个小进展、一句金句级对话。小爽点不必大，但每章必须有。
- **中爽点（3-5 章一个）**：一次完整的压抑-释放循环兑付——打脸完成、阶段升级、悬案告破。
- **大爽点（卷末）**：主线对抗的阶段了结 + 主角境况显著跃迁 + 新格局/新悬念展开。

排章节大纲时按此画曲线：先标出本卷的大爽点位置，再倒推中爽点，最后给每章配小爽点。

## 压抑-释放配比

- 有压才有放：爽点前必须有足够压抑（憋屈/危机/不公），但**压而不逾**——压抑段落不超过本章篇幅的 60%，且不能让主角显得蠢坏贱（读者弃书多在主角受气环节）。
- 释放要足：压抑 2 章的爽点，兑付篇幅不低于半章，写透读者情绪点，不一笔带过。
- 释放后留期待：大释放的结尾接新目标/新麻烦，不出现「无事可做」的空档章。

## 章尾钩子类型

危机逼近 / 悬念抛出 / 反转揭示 / 强期待（奖励就在眼前）。每章结尾四选一；连续两章用同型钩子后换型。钩子强度递进：卷末前三章的钩子一章比一章紧。

## 灌水警报（出现即调整）

- 一章写完没有信息量变化（人物不知道新东西、局面无变化、关系无推进）——这章是灌水章，砍或并。
- 对话超过 30 行没有冲突或新信息——压成 10 行。
- 同一情绪反复渲染超过 3 段——留 1 段。
- 主角连续 2 章被动挨打无反击动作或反击计划——节奏塌了，插入反击线。
